# KinDom Tech — recriação demonstrativa

Projeto independente de referência visual e funcional, desenvolvido em HTML, CSS e JavaScript puro. Não é o site oficial da KinDom Tech.

## Estrutura
- `index.html`: conteúdo e seções
- `css/style.css`: estilos, responsividade e animações
- `js/script.js`: navegação, módulos, demonstração de IA e formulário

## Executar
Abra `index.html` no navegador ou utilize a extensão Live Server no VS Code.

## Observações
- A demonstração da inteligência usa respostas predefinidas, não uma API real.
- O formulário valida campos, mas **não envia nem persiste dados**.
- O layout é uma recriação aproximada baseada na estrutura pública do site, não uma extração do código ou dos assets originais.
- Fontes do Google Fonts exigem internet; há fontes de fallback.
